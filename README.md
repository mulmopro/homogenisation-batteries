# Homogenized Lithium-Ion Battery Model — COMSOL Java API

COMSOL Java API implementation of a multiscale battery model combining periodic, three-dimensional cell problems with a one-dimensional homogenized electrochemical model.

## Model overview

The model contains two components:

| Component | Purpose | Dependent variables |
| --- | --- | --- |
| `comp1` — 3D | Periodic closure problems in the solid and liquid phases of an imported cell geometry | (`chis1`, `chis2`, `chis3`), (`chil1`, `chil2`, `chil3`) |
| `comp2` — 1D | Mass and charge transport across the negative electrode, separator, and positive electrode | `cs`, `cl`, `ps`, `pl` |

The closure problems impose periodic conditions on opposite cell faces and integral zero-mean constraints on each corrector. Their fluxes have the form `e_j + grad(chi_j)`. The longitudinal `zz` closure integrals are used in the 1D transport coefficients.

Both electrodes use the same closure solution. Different electrode morphologies require separate closure calculations or independently supplied effective coefficients.

The 1D model uses General Form PDE interfaces for liquid mass, liquid charge, solid mass, and solid charge. Electrode reactions use Butler–Volmer-type expressions with tabulated equilibrium potentials. Solid concentration is a macroscopic field defined on the electrode intervals, without an additional radial particle-diffusion coordinate.

## Repository contents

| File | Description |
| --- | --- |
| `BatteryHomog.java` | Java source that constructs the COMSOL model, imports input files, and defines the PDEs, mesh settings, and study sequence. |
| `geometry.mphbin` | COMSOL binary geometry used by the 3D closure component. |
| `Constants.txt` | Cell position and characteristic length parameters, loaded into the global parameter collection. |
| `ParametersH.txt` | Macroscopic dimensions, material properties, electrochemical parameters, and time settings, loaded into parameter group `par2`. |
| `Anode.txt` | Negative-electrode variable expressions, including effective properties, reaction kinetics, and initial conditions, loaded into `comp2/var1`. |
| `Cathode.txt` | Positive-electrode variable expressions, including effective properties, reaction kinetics, and initial conditions, loaded into `comp2/var2`. |
| `Separator.txt` | Separator variable expressions, including transport properties and initial conditions, loaded into `comp2/var3`. |
| `Eq_neg.txt` | Two-column table defining the negative-electrode equilibrium potential as a function of dimensionless concentration. |
| `Eq_pos.txt` | Two-column table defining the positive-electrode equilibrium potential as a function of dimensionless concentration. |

The text files supply the parameter values, variable expressions, and equilibrium-potential data used by the model.

## Input file format

**Preserve the existing file formats. Changing their structure, delimiters, quotation marks, or column order can make the files unreadable by COMSOL.** Keep the filenames and extensions unchanged unless the corresponding references in the Java source are updated.

### Parameter and variable files

`Constants.txt`, `ParametersH.txt`, `Anode.txt`, `Cathode.txt`, and `Separator.txt` use COMSOL's name, expression, and optional description format:

```text
L_neg "100 [um]" "Negative electrode thickness"
cs_max_neg "31507 [mol/m^3]" ""
```

When editing these files:

- Keep one parameter or variable per line.
- Preserve the order of the fields: name, expression, description.
- Preserve quotation marks around expressions containing spaces and around descriptions.
- Preserve unit syntax, such as `[um]` and `[mol/m^3]`.
- Use a decimal point for numeric values.
- Save as plain text; do not convert to a spreadsheet or rich-text format.

### Equilibrium-potential tables

`Eq_neg.txt` and `Eq_pos.txt` contain two numeric columns:

| Column | Quantity | Unit |
| --- | --- | --- |
| 1 | Dimensionless concentration, `cs/cs_max` | `1` |
| 2 | Equilibrium potential | `V` |

Example:

```text
0       4.44
0.032   4.34
0.102   4.23
```

Preserve the two-column layout and existing whitespace-separated format. Keep the first column in increasing order and use decimal points. Do not add column headings, units, or extra columns to these tables.

### Geometry file

`geometry.mphbin` is a binary file. Export geometry changes from COMSOL in the same format; do not edit this file with a text editor.

## Project directory and input paths

Place `BatteryHomog.java`, `geometry.mphbin`, and all seven `.txt` files in the same project directory.

The Java source obtains the input directory from the process working directory.
The working directory is the directory used by the running process, which can differ from the directory containing the Java or class file. Start COMSOL from the project directory using the commands below. All eight input files must be accessible in the working directory used by COMSOL.

## Windows commands — Windows 11 25H2

Open PowerShell. Replace the project and COMSOL installation paths below with the paths on your computer.

### 1. Enter the project directory

```powershell
Set-Location "C:\COMSOL_models\Battery"
```

### 2. Compile the Java source

```powershell
& "C:\Program Files\COMSOL\COMSOL64\Multiphysics\bin\win64\comsolcompile.exe" BatteryHomog.java
```

Compilation produces `BatteryHomog.class`.

### 3. Launch COMSOL

From the same PowerShell window:

```powershell
& "C:\Program Files\COMSOL\COMSOL64\Multiphysics\bin\win64\comsol.exe"
```

### 4. Open and compute the model

1. In COMSOL, select **File > Open**.
2. Select **Model Class File (*.class)** if needed and open `BatteryHomog.class`.
3. Build the geometry in both components using **Build All**.
4. Build both meshes.
5. Compute the study, which solves the stationary closure problems first and then the time-dependent electrochemical problem.
6. Save the model using **File > Save As** and select the `.mph` format.

## Linux commands — Ubuntu 24.04 LTS

Open a terminal. Replace the example project directory with your local path. The commands below assume that the COMSOL 6.4 `bin` directory is on `PATH`.

### 1. Enter the project directory

```bash
cd "$HOME/COMSOL_models/Battery"
```

### 2. Compile the Java source

```bash
comsol compile BatteryHomog.java
```

Compilation produces `BatteryHomog.class`.

### 3. Launch COMSOL

From the same terminal:

```bash
comsol
```

If COMSOL is not on `PATH`, invoke its executable using the installation path instead:

```bash
"/path/to/comsol64/multiphysics/bin/comsol" compile BatteryHomog.java
"/path/to/comsol64/multiphysics/bin/comsol"
```

Replace `/path/to/comsol64/multiphysics` with your COMSOL 6.4 installation directory.

### 4. Open and compute the model

2. Select **Model Class File (*.class)** if needed and open `BatteryHomog.class`.
3. Build the geometry in both components using **Build All**.
4. Build both meshes.
5. Compute the study, which solves the stationary closure problems first and then the time-dependent electrochemical problem.
6. Save the model using **File > Save As** and select the `.mph` format.

## Updating model inputs

To change parameter values, variable expressions, or equilibrium-potential data, edit the corresponding `.txt` files while preserving their format, then recreate the model by opening/running `BatteryHomog.class` again.

Changes to external input files do not require Java recompilation. Changes to `BatteryHomog.java` require recompilation before reopening the class. Editing an external file does not automatically update a model that has already been constructed.
